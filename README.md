## ❓ 这个仓库是什么？

> ⚠️ **重要提示：GitHub 上的这个仓库只包含 Python 源码（.py）和配置，不含打包好的 exe。**
>
> 仓库里没有二进制安装包 —— 请到下方的 [下载](#-下载) 区域取完整安装包（单文件 exe 或便携版）。
> 那才是「解压即用」的成品：Python 运行时、依赖库、图标、配置一应俱全。

**一句话：** 你把一批书交给它，它按「一 PDF 一文件夹」建好文件夹、用规范的夹名，并把这本书的所有配套文件（PDF、TXT、繁转简 TXT）一起搬进去。**移动前都能先看清单，不满意就改。**

### 谁需要它？

| 角色 | 场景 |
|:-----|:-----|
| 📚 **古籍 / 近代史研究者** | 几百上千册影印本、丛刊、史料集，按书目著录规范归档 |
| 🏛️ **图书馆 / 档案馆** | 扫描件批量归架，夹名统一含著者、出版项 |
| 📝 **文献整理者** | OCR 产物散落一地，先规范命名后缀，再按书归组 |
| 🤝 **和 Cathay 工具链一起用** | `_layered`/`_result` → `_PD6AIFOCR`，再著录归档 |

## 🎯 三个选项卡，各干一件事

三个选项卡**共用同一份「待处理」来源**（在任意一页拖入即可），彼此可只用其中一个。

| 选项卡 | 干什么 | 一句话 |
|:------|:-------|:-------|
| **① 后缀替换** | 把 `_layered` / `_result` 后缀换成 OCR 流水线规范后缀 | `某书_layered.pdf` → `某书_PD6AIFOCR.pdf`（繁体）/ `某书_PD6AIOCR.pdf`（简体），`_【繁转简】` 尾巴原样保留 |
| **② 繁简转换 + 编码规范化** | 繁体 TXT 生成简体副本；或把各种编码统一成 UTF-8 | 整合 **CathaySimplify 全部功能**，并新增「自动繁简判定」（默认繁体才转，简体不动） |
| **③ 著录建夹** | 抽书名/著者/译者/出版项/册数 → 建文件夹 → 把配套文件一起移入 | 本工具的主角：**一 PDF 一文件夹** |

**典型用法：** 先 ① 把 OCR 产物后缀规范 → 再 ②（需要时）繁简/编码统一 → 最后 ③ 著录建夹归档。

### 选项卡一：后缀替换
- 只认以 `_layered` / `_result` 结尾的文件（带 `_【繁转简】` 的也认）
- **按文字内容自动判定繁简**：繁体 → `_<版本>AIFOCR`，简体 → `_<版本>AIOCR`，其它语言 → `_<版本>AIOCR`
- 版本号自己填（默认 `PD6`，会记住），如 `PD5` / `PD6` / `PDVL6`
- 读不到文字的文件：**报错并跳过，原文件不动**
- 同一本书的所有产物整组统一后缀，不会一半 FOCR 一半 OCR

### 选项卡二：繁简转换 + 编码规范化（CathaySimplify 全部功能 + 扩充）
| 模式 | 默认产物 | 说明 |
|:-----|:--------|:-----|
| **繁简转换** | `X_【繁转简】.txt` | 方向可选：自动（繁体才转）/ 强制繁转简 / 强制简转繁 |
| **仅编码规范化** | `X_UTF8.txt`（或原地覆盖） | 识别 UTF-8 / UTF-8-BOM / GBK / GB2312 / BIG5 / UTF-16 → 统一 **UTF-8 无 BOM** |

- 转换引擎：**OpenCC**（词组级，如「頭髮→头发」「裡面→里面」），缺失时回退 zhconv
- 可选**加后缀另存**（原文件保留，默认）或**覆盖原文件**（先写临时文件再原子替换）
- 可指定统一输出目录；已是 UTF-8 无 BOM / 已经是转换产物 / 简体无需转 → 自动跳过（灰字标「无需处理」）
- 附**转换分析**：一对多、多对一字符统计，帮你看清 OpenCC 的转换边界

### 选项卡三：著录建夹
- 抽取 **书名 / 著者 / 国别 / 译者 / 出版地 / 出版社 / 出版年 / 册数 / 繁简 / 类别标签**
- 生成规范夹名，**建文件夹并把这本书的全部配套文件移入**
- 多卷 / 多册 / 多套**自动合并进一个文件夹**，册数 = 实际册数
- 界面双击可看**版权页原文**并当场改字段，改完立刻重建夹名
- 建夹前先看清单，可**只处理选中的行**，也可以把不想处理的行**移出列表**
- 黄底行 = 字段没把握；红底行 = 读不到文字/非图书，需人工

## ✨ 核心特性

| 特性 | 说明 |
|:-----|:-----|
| 🖱️ **拖放即用** | 文件、文件夹直接拖进窗口；文件夹**递归**处理子目录 |
| 🧩 **配套文件一起走** | 同一本书的 `X.pdf` + `X.txt` + `X_【繁转简】.txt` 整组归位，不会只搬一半 |
| 🧹 **夹名噪声清洗** | 自动去掉 `OCR` / `OPT` / `OCR优化` / `ORPALIS优化` / `zhelper-search` / `_PD6AIFOCR` / `_layered` / `8 位以上编号` / 孤立单字母 等流水线噪声 |
| 🔤 **夹名一律简体** | 繁体书名自动转简体（原文为繁体的另加 `【繁体】`），英文版加 `【英文】` |
| 📅 **年份智能兜底** | 版权页 → CIP → 文件名里的年份，层层兜底；全角数字（`２０１６`）自动归一 |
| 🧾 **不 OCR、不 AI、不联网** | 只读已有的 TXT / PDF 文字层，读不到就标红交人工，**绝不瞎猜** |
| 🔍 **出错有黑匣子** | 界面异常自动写入 exe 旁的 `_error.log`；`--selftest` 一键体检；`--cli` 可无界面批跑 |
| 🔁 **多卷合并** | 「第N册 / 第N卷 / 上·下 / 其一」等同套书自动并成一夹，`（全N册）` |

```
1. 解压安装包 → 双击【图书自动著录软件】（或 著录.bat）
2. 等 2~10 秒，主界面弹出
```

## 🧭 命名规则（重要）

**夹名模板：**

```
[编号] 书名（全N册）【繁体】/【英文】（[国别 ]著者[著/编/编著/主编/撰] [译者译] 出版地 出版社年[ 备注]）（类别标签）
```

- **一 PDF 一文件夹**：不合并不同书，不多卷混进同一夹（同一套书的多册除外）
- **配套文件一起归位**：PDF、OCR TXT、繁转简 TXT 全部进同一个文件夹
- **册数**：单册一律写 `（全1册）`；多卷写 `（全N册）`
- **夹名一律简体**；原文为繁体加 `【繁体】`，英文版加 `【英文】`
- **类别标签**（如 `（民族学与人类学教材）`）放在**最后**，且**只取自源文件名**，不自行指派
- **著者与出版地之间一个半角空格**：`（李致忠著 北京 书目文献出版社1990年）`
- **明显不是书的文件不建夹**：`说明.txt` / `目录.txt` / `封面` / `readme` / `凡例` 一类且无著录信息 → 标红「需人工」，不动它
- **编号前缀**（如 `03、`）默认拼在夹名最前，可在界面取消勾选

**示例：**

```
03、毛泽东传（三）（全1册）（中共中央文献研究室编 北京 中央文献出版社 2013年）
中华大典 民俗典 口头民俗（全3册）【繁体】（北京同心出版社 2011年）
西藏问题 民国政府的边疆与民族政治（全1册）【繁体】（中文大学出版社）
```

## 🧠 字段从哪来（不 OCR、不 AI）

**读取优先级**（目录里的文件同名成组后就成了一本"书"）：

1. **文件名里写了的最先用**：`《书名》`、`XX出版社`、`20XX年`、`第N册`
2. 否则读 `<名>_result.txt` / `<名>_PD6AIFOCR.txt` 等文本产物里的**版权页 / CIP 行**
3. 否则读 **PDF 自带文字层**（PyMuPDF，不 OCR）
4. 全都没有 → 界面标红，交人工填

**年份取值顺序**：`第 1 版` → CIP 行 → 版权页定价行 → **文件名里的年份**

## 🛠️ 从源码运行 / 自己打包

```bash
# 1. 装依赖（只需一次）
pip install -r requirements.txt

# 2. 直接运行界面
python gui.py

# 3. 或者用命令行批跑（不开界面，结果写 _cli.log）
python gui.py --cli "D:\某目录"            # 只扫描，不动文件
python gui.py --cli "D:\某目录" --apply    # 真的建夹并移动

# 4. 环境体检（写 _selftest.txt）
python gui.py --selftest
```

**打包成单文件 exe：**

```bash
# 直接双击 打包EXE.bat，或手动执行：
pyinstaller --noconfirm --clean --onefile --windowed --name CathayShelf ^
  --icon app.ico --add-data "app.ico;." --add-data "config;config" ^
  --collect-all tkinterdnd2 --collect-all opencc --collect-all zhconv ^
  --hidden-import chardet --hidden-import zhconv gui.py
```

> ⚠️ **打包要点**：`--collect-all zhconv` **不能省**！zhconv 的字典是运行时才加载的**数据文件**，
> 只写 `--hidden-import zhconv` 会打出"一调用就崩"的 exe（v0.4.3 修复的正是这个坑）。
> 同理 opencc 的词典数据也要 `--collect-all opencc`。

**依赖清单**：`PyMuPDF`（PDF 文字层读写）、`tkinterdnd2`（拖放）、`opencc-python-reimplemented` + `zhconv`（繁简转换）、`chardet`（编码探测）。

## ❓ 常见问题

<details>
<summary><b>会不会把我的文件弄乱？</b></summary>

不会乱，但**确实会移动文件**——这正是它的工作。防呆措施：
① 扫描后**先出清单**，黄底/红底行会提示没把握的条目，双击可改；
② 可以**只勾选几行**处理，也可以把行**移出列表**；
③ 建议第一次拿**副本目录**试跑；
④ 建夹移动只是把配套文件放进新建的同级文件夹，**不改文件名、不改内容**。
</details>

<details>
<summary><b>为什么有些书的括号里是空的「（）」？</b></summary>

说明这本书**没有版权页信息**（常见于民国影印本、内部资料）。工具坚持「读不到就不编」，所以留空并在界面标红，交你人工补。想批量补，可在界面双击逐条填出版地/出版社/年。
</details>

<details>
<summary><b>为什么它不帮我 OCR？</b></summary>

故意的。OCR 交给 [CathayOCR](https://github.com/zzhjim02/CathayOCR)，本工具专注"著录与归架"这一件事：只读**已有**的 TXT 或 PDF 文字层。这样它**不联网、不用 AI、结果可复核**，速度也快（337 本扫描约 1 分钟）。
</details>

<details>
<summary><b>「说明.txt」「目录.txt」也被建成文件夹了？</b></summary>

v0.4.3 已修：这类**明显不是书**又没有著录信息的文件会标红「需人工」，不再建夹。若遇到别的误判，把文件名告诉我加进规则即可。
</details>

<details>
<summary><b>多卷合并规则是什么？</b></summary>

同一套书的多册（`第N册`/`第N卷`/`（上）`/`（一）`/结尾卷次数字）会并进**同一个文件夹**，册数按实际册数写 `（全N册）`。不同书不会合并。
</details>

<details>
<summary><b>夹名里的编号前缀能去掉吗？</b></summary>

能。界面左下角「保留原文件名编号前缀」取消勾选即可（例如去掉 `03、`）。
</details>

<details>
<summary><b>和 CathaySimplify 什么关系？</b></summary>

**CathayShelf 已整合 CathaySimplify 的全部功能**（繁简双向转换 + 编码统一），并新增**自动繁简判定**、**修好了递归扫描**、把转换分析并进了统一的清单界面。装了本工具就不必再单独装 CathaySimplify。
</details>

<details>
<summary><b>支持 Apple / 手机吗？</b></summary>

目前只做 Windows 桌面版（tkinter + PyMuPDF）。
</details>
